# Hybrid Architectures

**RL "Controller" around a ReAct Core**:

![1780233033969](image/7.HybridArchitectures/1780233033969.png)

* **Pros**
  * Keeps strong general reasoning while improving repeated decisions over time.
  * Can be sample-efficient if learning is focused (routing/bandits).
  * **Easier to Safety-Gate:** Learn only within constrained action spaces.
* **Cons**
  * **More Moving Parts:** Debugging and evaluation become system level.
  * Credit assignment across modules (router vs. ReAct core) can be ambiguous.
  * **Non-Stationarity:** Tool changes can break learned routing unless monitored.
