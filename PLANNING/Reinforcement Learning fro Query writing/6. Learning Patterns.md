### How to Align the LLM Agents ( Alignment-Oriented)

**PPO** vs **DPO** Style:

- **Proximal Proxy Optimization (PPO)-Style**: Train a reward model from preference data, then fine-tune the policy to maximize the reward.
  - Policy
- **Direct Preferences Optimization (DPO)-Style**: Skip an explicit reward model; directly optimize the policy using preference pairs.
  - User Preferences

# Learning Pattern 1: Memory Centric Learning

- Mainting an **episodic memory** (which episode are we)

  - Tool sequences
  - Common failures
  - Canonical Procedures
- Retrieve Memories Conditionally:

  - Similarity search on task + context.
  - "Failure-triggered" retrieval (tool error or confidence drops)
- It convertes past experience onto state augmentation
- Risks:

  - Stale/incorrect memories
  - Security constraints
  - Same solutions over and over again instead of explore new solutions
